# YE YANRAN Personal Website

Minimal static personal website for GitHub Pages.

## Local preview

Open `index.html` in a browser.

## GitHub Pages

Create a public GitHub repository named:

```text
YE-NONO.github.io
```

Upload these files to the repository root:

- `index.html`
- `styles.css`
- `assets/researchmap-logo.png`
- `assets/shinshu-icon.png`
- `.nojekyll`

The site will be available at:

```text
https://ye-nono.github.io/
```

GitHub Pages may take a few minutes to publish changes after each push.
